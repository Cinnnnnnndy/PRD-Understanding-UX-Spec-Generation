交互序列 · 数据流
① 输入偏移量 → 字段解析
USER INPUT
用户在 HEX 框输入
0x18040600
▼
PARSE
parseLoose(raw, 32)
→ word = 0x18040600
▼
DECOMPOSE
decomposeWord(word)
func=6, cmd=0x0401
ms=1, rw=0, param=0
▼
STATE UPDATE
state.fields = result
→ 标记 dirty，触发重绘
▼
RENDER
refresh全局()
→ 位图 + 字段卡片全同步
② 字段编辑 → 回合成
FIELD INPUT
用户修改 func 字段
输入 12
▼
VALIDATE
parseLoose(raw, 6bit)
0 ≤ v ≤ 63 → ✓
合法值 v = 12
▼
STATE PATCH
state.fields[func] = 12
其余字段保持不变
▼
COMPOSE
composeWord()
→ 新 32-bit 字
0x30040600
▼
SYNC
顶部 HEX/DEC 同步
+ 位图高亮更新
