# SMC 偏移量计算器 · 业务逻辑梳理

## 非纯展示逻辑清单

| UI 区域 | 业务规则 | 规则来源 | 类型 |
|---------|---------|---------|------|
| 实时结果区 | 5 字段全部合法才显示计算值，否则显示 `0x--------`/`-`（红） | `isValidField` × 5 | 前端业务逻辑 |
| 实时结果区 | 字段变更后 300ms 防抖再计算 | `DEBOUNCE_DELAY` | 纯展示/性能 |
| 单字段输入 | 实时过滤：转大写、去非十六进制字符、按 `maxLen` 截断 | `input` 事件 | 前端业务逻辑 |
| 单字段输入 | blur 时校验 `≤ maxValue`，超出加 `.invalid` 红字 + 字段错误文案 | `blur` 事件 | 前端业务逻辑 |
| 解析按钮 | 十进制/十六进制(`0x`)偏移量 → 5 字段回填 | `parseDecimalOffset` | 前端业务逻辑 |
| 解析按钮 | `> 0xFFFFFFFF` 时取低 32 位并告警，不阻断 | `MAX_U32` 判断 | 前端业务逻辑 |
| 应用按钮 | 全字段合法才计算并回写十进制输入框，否则红色错误提示 | `applyBtn` handler | 前端业务逻辑 |
| 应用按钮 | 计算成功后把结果写回 `#offsetDecimal` | `applyBtn` handler | 前端业务逻辑（隐式联动） |
| 取消按钮 | 复位全部字段到默认值、清错误/警告/结果 | `cancelBtn` handler | 纯展示 |
| Enter 键 | 字段内回车 = 点「应用」；十进制框回车 = 点「解析」 | `keydown` | 纯展示/快捷 |

## 三类逻辑区分

- **纯展示逻辑**：防抖、Enter 快捷键、取消复位、结果区颜色切换 → 前端完整实现，无需协同。
- **前端业务逻辑**：位字段编解码、范围校验、十六进制过滤、溢出截断告警 → 前端实现，但**规则细节需与协议方确认**（见下）。
- **后端/规格业务逻辑**：功能码枚举语义、保留/OEM 区段定义、功能码×命令码合法组合 → 由协议规格定义，当前以 tooltip 硬编码代替，理想由宿主下发。

## 校验规则（精确）

```
单字段合法 ⟺ 是整数 ∧ ≥0 ∧ ≤ maxValue
  function  ≤ 0x3F     command ≤ 0xFFFF
  ms ≤ 0x1   rw ≤ 0x1   parameter ≤ 0xFF
parseHexInput：trim 后必须整串匹配 /^[0-9A-Fa-f]+$/，否则 NaN（空串=NaN）
十进制解析：以 0x/0X 开头按 16 进制，否则 10 进制；NaN 或 <0 判非法
```

> **校验缺口（设计/工程注意）**：
> - 功能码只判 `≤0x3F`，**不拦截**保留位 `0x20`、未定义空洞 `0x0A–0x1F`/`0x21–0x36`。语义非法值能通过校验。
> - 空字段：`parseHexInput('')` = NaN → 判非法。但默认值非空（`00`），所以「清空某字段」会让结果跳到 `0x--------`，与「真正错误」同视觉，无区分。

## 状态机（结果区）

```
        ┌────────────── 任一字段非法 / 被清空 ──────────────┐
        ▼                                                   │
[INVALID 0x--------/- 红]                          [VALID 0x________/dec 蓝]
        │                                                   ▲
        └────────────── 全字段回到合法 ─────────────────────┘
初始：全默认值 → VALID(0x00000000)   ← 注意：零值=合法态，非空态
```

## 操作顺序约束

- **无强制顺序**：5 个字段可任意顺序填写；实时结果随时更新。
- **双向入口互斥但可互转**：既可「填字段→看结果」，也可「填十进制→解析成字段」。两条路径最终汇聚到同一组字段状态。
- **依赖**：「应用」依赖「全字段合法」前置；「解析」依赖「十进制输入非空且可解析」前置。
